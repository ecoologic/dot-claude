1. ALWAYS follow the active output style in both chat and docs (too often ignored!)
1. List the root `README.md` section headings with `grep -n '^#' README.md`; read a section only when the task needs it

1. Before you plan or edit in `packages/{x}/`, read `packages/{x}/CLAUDE.md` and each frontmatter in `packages/{x}/.claude/skills/*/SKILL.md`
1. Before you start a task, invoke each skill whose description matches it and  each memory file whose `MEMORY.md` hook suggests it's relevant
1. Re-read these instructions periodically throughout the chat
